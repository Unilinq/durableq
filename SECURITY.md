# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it
through one of:

- GitHub private vulnerability reporting: open the Security tab on
  https://github.com/unilinq/durableq and choose "Report a vulnerability".
- Email: info@unilinq.ai

We aim to acknowledge reports within 3 business days.

## Supported versions

DurableQ is pre-1.0. Only the latest minor release receives security fixes.
Once the project reaches 1.0, this policy will be updated to cover a normal
support window.
